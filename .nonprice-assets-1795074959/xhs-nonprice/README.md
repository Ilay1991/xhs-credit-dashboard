# 小红书「非低价」图文 SKILL 交付包

依据飞书文档《信贷行业小红书非低价图文SKILL》（wiki `BajuwnKRgiXWBRknOlzcBYa4nAX`）构建。

## 目录

```
skill/xhs-credit-nonprice/      ← skill 本体，直接拷进 ~/.claude/skills/
  SKILL.md                      主流程：定输入 → 标题 → 图片 → 正文 → 自检 → 输出
  references/
    标题公式.md                 5 类句式 + 实例 + 和首图的分工
    首图规范.md                 尺寸/字体/高亮/logo/风险提示语 + 15 套模板
    正文三模块.md               钩子 3 种打法 + 铺垫纪律 + 完整示例
    产品卖点.md                 3 个卖点 + 强度排序 + 表述纪律
    合规红线.md                 禁用词 / 必须带前提 / 利率检查清单 / 发布前自检
    评分卡.md                   四维 0 分到满分的判定标准

covers/                         5 张首图成品
  n1..n5.png                    1080×1440 PNG，可直接上传
  n1..n5.svg                    源文件，改文案改这里
  logo.png                      度小满官方 app icon（出图必需）

scripts/
  build-nonprice.js             SVG 出图脚本（5 套模板）
  notes-nonprice.js             笔记机检脚本（字数/红线/钱要素窗口）
  logo.png                      同上，脚本同目录读取

5篇示例笔记.md                   5 篇完整四件套 + 自检分 + 覆盖面说明
```

## 安装

```bash
cp -R skill/xhs-credit-nonprice ~/.claude/skills/
```

之后 `/xhs-credit-nonprice` 即可调用。

注：`SKILL.md` 末尾「要出图时」那段引用的是出包机器上的绝对路径，换机后改成你自己放 `scripts/` 的位置。

## 出图

```bash
cd scripts
node build-nonprice.js            # 生成 n1..n5.svg

# SVG → PNG。不要用 qlmanage（输出正方形）或 sips（中心裁切，会裁掉 logo 和风险提示语）
for f in n1 n2 n3 n4 n5; do
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
    --headless --disable-gpu --hide-scrollbars \
    --screenshot="$f.png" --window-size=1080,1440 \
    --default-background-color=00000000 "$f.svg"
done
```

改文案：编辑 `build-nonprice.js` 顶部的 `notes` 数组，格式
`[文件名, 第1行, 高亮行, 第3行, 背景色, 字色, 模板]`。
模板可选 `手写 / 提问 / 清新 / 柔和 / 科技`。

**深色底（科技模板）只能用 `block` 高亮，不能用 `band`**——band 只压文字下半部分，上半截会黑底黑字消失。这个坑已经在脚本里注掉了。

## 机检

```bash
node scripts/notes-nonprice.js
```

逐条检查：标题字数（半角按 0.5 计）、emoji 数、正文 ≤220 字、钱要素是否落在第 20–35 字、标签数与必带标签（#度小满 #急用钱 #缺钱），以及红线正则——「低」与息费同句 / 时效承诺 / 4.9% 残留 / 20万缺「最高可达」/ 24期缺「最长」/ 7.2% 缺「起」。

改完文案跑一遍再发。

## 和低价版 skill 的分野

核心自检一句话：**把 4.9% 删掉，这篇还站得住吗？** 站不住就是写成低价版了，回炉。

| | 低价版 | 非低价版（本包） |
|-|-|-|
| 核心钩子 | 首借 4.9%、1 万一年利息约 271 元 | **最高可达 20 万额度 + 最长 24 期** |
| 利率怎么说 | 当卖点讲 | 只当息费透明的证据，提一句 7.2% 起 |
| 风险提示语 | 带 4.9% 首借两行的五行版 | **不带 4.9% 的三行版** |
| 适用客群 | 拉新、没借过的 | 看额度、看期限、比平台靠谱度的 |

## 源文档里三处自相矛盾，本包的处置

落地时按需跟业务方对齐，有官方口径就替换。

1. **自检满分对不上**——分数列写 3/2/2/1（和为 8），阈值写「≥8，满分 10」。若满分真是 8，阈值 ≥8 等于要求满分，不合理。
   **处置**：按原文的相对权重次序（图片 > 标题 > 钩子 > 卖点，与搜索场域权重一致）补齐为 **图片 4 / 标题 3 / 钩子 2 / 卖点 1 = 10**，阈值 ≥8 且无 0 分项。已在 `评分卡.md` 开头标注。

2. **正文字数 200 还是 220**——第一节表格写 ≤200，Step 4 和第六节都写「不超过 220 字」。
   **处置**：取 **220 为硬上限、200 为目标值**。机检脚本按 220 卡。5 篇示例实际都在 180 以内。

3. **附录「优质素材」违反自家红线**——多张素材写着「最快 1 分钟放款 / 信息审核仅需 1 分钟即可放款」，而第八节明令禁止时效承诺；另有一张写「利息比预期低」，撞「低」字红线。
   **处置**：在 `产品卖点.md` 标注为历史素材，不要照抄；机检脚本会拦截这两类表达。

## 一个投放判断（非文档原文，供参考）

15 套首图模板全部围绕同一句「怎么还有人不知道小红书上的度小满可以借钱」，属于**平台借力**类。但该类型在 9 月投放数据里授信率最低（2.17%）、授信成本最高（1,572 元）。

建议：**首图用平台借力抓眼球，标题换成人情成本或场景痛点**，两边互补，不要同时押在一个方向上。本包 5 篇示例的标题就是按这个分的。
