# 正文三模块

## 篇幅

**正文 ≤220 字**，风险提示语（免责声明）不计入。

## 结构

| 模块 | 功能定义 |
|-|-|
| ① 钩子 | 前 3 秒制造认知摩擦或情绪冲击，强行留人 |
| ② 铺垫 | 把钩子兑现成与 23–50 岁受众相关的具体内容 |
| ③ 产品卖点 | 讲透 1–2 个，不需要全面铺开 |

**开头钩子和标题强呼应，两者形成信息补充**——标题说了一半，钩子补另一半，不要重复。

**钱要素**（钱/借贷/额度/利率/支出/急用钱）首次出现必须落在**第 20–35 字**。

## ① 钩子：三种打法

钩子的本质是**把标题详细展开**，让用户更真实地感知到缺钱、找人借钱的痛点，从而激发找平台的需求。

### A. 信息差填补

揭露观众不知道的行业现实或财务真相。适用：场景痛点 / 人情成本 / **疑虑解答 / 反常识挑战 / 平台借力**。

- 真的别说后悔没早点知道，居然还有人不了解这个信息差
- 前几天突发情况急需钱周转，当时对比过好几个平台，大多都藏着看不懂的费用
- 清醒女孩都在用的借款方式，真的不要再说后悔没早点知道了😭
- 大数据推给急用钱的宝子！不会还有人不知道，在小红书就能用度小满借钱吧！
- 前阵子我突然要交房租，工资还没发，差点急哭！

### B. 真实经历展开

用有细节的故事补充标题。适用：场景痛点 / 人情成本 / **疑虑解答 / 平台借力**。

- 急需 8 万块周转，纠结了好几天😩——找父母开口吧，怕他们担心
- 身为一个资深「周转党」，我太懂急需用钱时到处找渠道的焦灼了。朋友问遍、平台比对，就想找个额度够、速度稳还正规的地方

**细节是关键**：「8 万块」「纠结了好几天」「怕他们担心」——三个具体信息才叫真实经历。换成「我之前急需用钱」就是 1 分。

### C. 痛点场景共情

描绘受众真实困境，让观众觉得「说的就是我」。适用：场景痛点 / 人情成本 / **疑虑解答 / 平台借力**。

- 生活突然发生紧急事件，人都不一定反应得过来，更何况钱包……🤯
- 到处求人借钱，东拼西凑还是不够……那种感觉，真的太难受了😭
- 生活里难免碰上急用钱的时候，找朋友借吧，又不好意思开口，怕欠人情

## ② 铺垫：1–2 句，不允许多次铺垫

**通常就是「产品 + 一句话总结」。**

- 用【度小满】借钱！最高可达 20 万额度，先申请备着
- 后来姐妹推荐了度小满，发现真的比想象中靠谱多了！
- 关键时刻还得是正规平台靠谱。选来选去，还是度小满最让人放心

**非低价纪律**：铺垫句里不要写「新人活动很良心 / 首借 4.9%」——那是低价版的铺垫。非低价的铺垫落在**额度够、期限长、平台正规**上。

**多次铺垫是重罪**：铺垫 → 卖点 → 又回来铺垫 → 再讲卖点，这叫传动，传动 ≥2 次直接扣到 0 分。

## ③ 产品卖点

见 `产品卖点.md`。卖点二必须出现，1–2 个讲透，列点式短平快。

## 完整示例（非低价，生活应急）

> 生活里难免碰上急用钱的时候，找朋友借吧，又不好意思开口，怕欠人情。
>
> 别愁啦，关键时刻还得是正规平台靠谱——我选的度小满。
>
> ✅ 额度够：最高可达 20 万，应急完全够
> ✅ 期限长：最长可分 24 期，慢慢还、月供压力小
> ✅ 用着放心：额度不使用不收费，先申请备着也不花钱
>
> 年化利率 7.2% 起，按日计息，息费写得明明白白。
>
> 不想欠人情又手头紧的宝子，可以自己去看看能批多少。

字数 177，钱要素「急用钱」出现在第 9 字——偏早。调整：把开头改成「生活里难免碰上过不去的坎儿，人都不一定反应得过来，更何况钱包」，钱要素落到第 28 字。

## 常见扣分点

| 扣分 | 症状 |
|-|-|
| 钩子说明文 | 「现在借钱很方便」——产品视角，不是用户视角 |
| 痛点太模糊 | 「有时候需要钱」——没有任何具体困境 |
| 多次铺垫 | 产品名出现 3 次以上，每次都重新铺一遍 |
| 卖点堆砌 | 3 个卖点全上，每个一句话，一个都没讲透 |
| 钱要素过晚 | 到 60 字还没出现钱，用户已经划走 |
| 写成了低价版 | 删掉 4.9% 后整篇垮掉 |
