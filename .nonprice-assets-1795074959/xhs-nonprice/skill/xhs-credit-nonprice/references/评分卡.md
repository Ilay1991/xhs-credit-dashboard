# 评分卡

生成后逐项真打分。**通过阈值：总分 ≥8（满分 10）且无 0 分项。**

> 原文档的分数列写的是 3/2/2/1（和为 8），但阈值写「≥8，满分 10」。两者对不上。
> 这里按原文的**相对权重次序**（图片 > 标题 > 钩子 > 卖点，与搜索场域权重一致）把满分补齐到 10：
> **图片 4 / 标题 3 / 钩子 2 / 卖点 1**。如业务方给出官方口径，按官方口径替换。

---

## 一、图片（0–4 分）

**核心问题：有无清晰突出重点，符合小红书原生风？**

| 分 | 判定 |
|-|-|
| **4** | 一眼能看到唯一焦点；高亮 2–4 字；颜色 ≤3；字号 ≥128；logo 小且在左上角；底部风险提示语完整不压字；像用户笔记不像广告 |
| **3** | 上面有一项不达标，但焦点仍清晰（比如颜色 4 色、字号 120） |
| **2** | 焦点存在但不强（高亮 5–6 字，或字号偏小需凑近看） |
| **1** | 有文字但没有视觉焦点（高亮整行 / 全篇一个色调 / 文案 >20 字排得密） |
| **0** | **缺风险提示语**、**缺 logo**、尺寸不是 1080×1440，或明显是广告设计稿而非原生笔记 |

0 分项记住：**风险提示语和 logo 是过审硬条件，缺了不是扣分，是不能发。**

## 二、标题（0–3 分）

**核心问题：有无搜索关键词，能否第一时间吸引用户？**

| 分 | 判定 |
|-|-|
| **3** | ≤20 字 + 前 16 字含关键词 + 有具体利益点或痛点（带数字/带情绪）+ 和首图互补不重复 |
| **2** | 规范全达标，但利益点偏泛（「靠谱」「方便」这类），或和首图信息重复 |
| **1** | 关键词在 16 字之后，或 emoji ≥3 个，或超 20 字 |
| **0** | **没有任何关键词**，或纯空泛感叹（「真的太香了！」），对不上搜索意图 |

## 三、正文钩子（0–2 分）

**核心问题：有没有让用户感同身受，吸引到真的需要借钱的用户？**

| 分 | 判定 |
|-|-|
| **2** | 开头即具体困境（有金额、有时间、有情绪三者中至少两个）；钱要素落在第 20–35 字；和标题互补 |
| **1** | 有痛点但模糊（「有时候需要钱」），或钱要素窗口偏了（<20 字 / >35 字） |
| **0** | 开头是产品说明（「度小满是一个正规平台」）或平台口吻（「现在借钱很方便」）——吸引不到任何借钱需求用户 |

判法：**把开头第一句单独拿出来**，有借钱需求的人看了会不会往下划？不会就是 0。

## 四、产品卖点（0–1 分）

**核心问题：是否包含 2 个及以上卖点，用短平快话术清晰表达？**

| 分 | 判定 |
|-|-|
| **1** | ≥2 个卖点 + 卖点二在内 + 列点式短句 + 表述全合规（最高可达/最长/起） |
| **0** | 只有 1 个卖点，或卖点二缺失，或长段落糊成一团，或表述违规 |

## 处置规则

| 情况 | 动作 |
|-|-|
| 总分 ≥8 且无 0 分项 | **输出** |
| 任一项 0 分 | **直接重写，不看总分**——0 分是结构性缺陷，补不回来 |
| 总分 <8 但无 0 分项 | **只改失分项**，不要整篇重写（整篇重写会改坏已达标维度） |

## 额外的两道一票否决

这两条不在分数里，但不过就不能发：

1. **红线扫描**（见 `合规红线.md` 末尾的自检清单）——任一条不过，不能发
2. **删 4.9% 测试**——文中若出现 4.9%/首借福利/新人活动，说明写成低价版了，回炉

## 自检输出格式

```
【自检】图片 x/4 | 标题 x/3 | 钩子 x/2 | 卖点 x/1 | 总分 x/10
【红线】低字○ 时效○ 最高可达○ 最长○ 起○ 无4.9%○ 图片提示语○
```

分数必须真打，不能默认满分。低于阈值不要输出，先重写。
