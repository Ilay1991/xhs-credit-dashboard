# 首图规范

图片是搜索场域权重最高的位置（图片 > 标题 > 正文 > 标签 > 评论区）。**信贷默认一张图。**

## 画布与排版

| 项 | 规格 |
|-|-|
| 尺寸 | **1080 × 1440（3:4）** |
| 格式 | 文字图用 **PNG**（清晰锐利）；导出前确认 **sRGB**，加 USM 锐化 40–60% 补偿平台压缩 |
| 字体 | **抖音美好体**，字号 **156** |
| 行间距 | **≥1.3 倍字号** |
| 文案 | **≤20 字**，比标题更短更狠 |
| 颜色数 | **≤3** |
| 高亮 | 荧光黄 `#FFE94D` 或其他适配色，**仅 2–4 字** |
| 风格 | 原生风，减少品牌元素露出，和用户日常刷到的内容同质 |

本机没装抖音美好体时的降级顺序：`PingFang SC`（黑体风，weight 900）→ `Songti SC`（手写/书摘风）。降级后字号要相应下调到 128–200 区间视觉配平，不要死守 156。

## 三条硬性要求

缺任一条**不能过审**：

1. **左上角度小满 logo**——用官方 app icon（`xhs_covers/logo.png`），圆角裁切，120×120，位置 `translate(56, 52)`。**不要手绘 logo。**
2. **底部居中风险提示语**，字号 16（1080 宽画布上按 24px 渲染），灰色小字
3. **高亮只 2–4 字**——高亮一整行等于没高亮

## 风险提示语（非低价版，三行）

**不要用带 4.9% 首借的五行版——那是低价版的。**

```
年化利率（单利）7.2%-24%，贷款额度、放款时间、还款方式、还款期限等以实际审批结果为准
贷款有风险，借款需谨慎，请根据个人能力合理贷款，理性消费，避免逾期
服务来源于重庆度小满小额贷款有限公司及合作金融机构，服务网址 https://www.duxiaoman.com
```

位置：图片最下方，居中，字号 16。免责声明不计入正文字数。

## 模板主推文案方向

15 套模板全部围绕同一句：

> 怎么还有人不知道 **小红书上的度小满** 可以借钱

高亮落在「小红书」或「度小满」（2–4 字）。变体：

- 居然还有人不知道小红书上度小满就能借到钱
- 小红书上的度小满真的能借钱！
- 急需 6 万块 哪个平台靠谱！！

非低价场景下建议把数字换成**额度**（急需 6 万 / 一下周转 10w），不要换成利率。

## 常见扣分点

| 扣分 | 原因 |
|-|-|
| 高亮整行 | 高亮超过 4 字，等于没有视觉焦点 |
| 字号 ≤100 | 手机信息流里看不清，原生风变廉价感 |
| 颜色 >3 | 像广告，不像用户笔记 |
| logo 居中/过大 | 品牌元素过露，算法和用户都会判定为硬广 |
| 风险提示语缺失/压字 | 直接不过审 |
| 行间距 <1.3 倍 | 大字号下会糊成一团 |

## 渲染管线（本机）

SVG → Chrome headless → PNG。**不要用 qlmanage（输出正方形）或 sips（会中心裁切，裁掉 logo 和风险提示语）。**

```bash
node build-nonprice.js
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --screenshot=01.png \
  --window-size=1080,1440 --default-background-color=0 01.svg
```
