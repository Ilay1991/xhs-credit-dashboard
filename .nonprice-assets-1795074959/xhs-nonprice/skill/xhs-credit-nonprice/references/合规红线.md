# 合规红线

## 绝对禁止出现的表达

| 禁止 | 原因 |
|-|-|
| **低息** / 利息低 / 利率低 / 息费低 | 明令禁用词。**「低」字与息费类词同句出现即违规，不要求连写**；口语化变体（便宜、划算、省钱）同样禁止 |
| 最快 1 分钟到账 / 秒到 / 极速到账 / 马上放款 | 时效承诺，不可兑现 |
| 额度 20w（漏「最高可达」） | 必须保留上限表述 |
| 人人可享 / 都能参加 / 都能借 | 历史授信失败用户无法参加 |
| 零门槛 / 包过 / 黑户可做 / 无视征信 | 绝对化 + 违规承诺 |
| 在校大学生可参与 | 明确排除人群 |

**「低」字陷阱的具体判法**：同一个句子里只要同时出现「低」和（息/费/利率/利息/成本）中任一个，就算违规。

- ❌ 比别家低不少，息费也透明
- ❌ 利率比我想的低
- ❌ 成本更低一点
- ✅ 息费透明，按日计息
- ✅ 利率写进合同，提前还款没有违约金

## 必须带前提的表达

| 表达 | 必须带的前提 |
|-|-|
| 20w | 「**最高可达**」 |
| 24 期 | 「**最长**」 |
| 7.2% | 「**起**」 |

## 利率表述检查清单

两种**预先核准**的完整写法，直接用，不要自己造：

1. `年化利率 7.2% 起，万元日息 2 元起`
2. `年化利率 7.2% 起，借 1w，按等额本息 1 年利息约 397 元`

**只要你写了具体利息金额**，下面四项缺一不可：

- ☐ 有「**年化**」二字
- ☐ 有「**等额本息**」还款方式
- ☐ 有「**一年**」期限前提
- ☐ 有「**约**」字

用写法 1（万元日息）时不需要后三项——它没有给出总额，不构成金额承诺。

## 非低价专属红线

| 禁止 | 原因 |
|-|-|
| 新人首借年化 4.9% | **这是低价版的卖点，非低价笔记一律不提** |
| 借 1 万元 1 年利息约 271 元 | 同上，这是 4.9% 对应的金额 |
| 首借福利 / 新人活动 | 同上 |
| 带 4.9% 的五行版风险提示语 | 非低价用三行版 |

## 发布前的红线自检（逐条打勾）

- ☐ 全文搜一遍「低」字，确认没和息费类词同句
- ☐ 搜「分钟」「秒」「马上」「立刻」，确认没有时效承诺
- ☐ 搜「20」，确认每处都带「最高可达」

- ☐ 搜「7.2」，确认都带「起」
- ☐ 搜「4.9」，确认**一处都没有**（非低价）
