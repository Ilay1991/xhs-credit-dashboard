# 度小满小红书「非低价」图文笔记生成

## 这个 skill 和低价版的区别（先看这段）

**非低价 = 不拿「新人首借年化 4.9%」当卖点。**

| | 低价版 | **非低价版（本 skill）** |
|-|-|-|
| 核心钩子 | 首借 4.9%、1 万一年利息约 271 元 | **最高可达 20 万额度 + 最长 24 期** |
| 利率怎么说 | 当卖点讲 | 只当**信息透明的证据**提一句：年化利率 7.2% 起 |
| 风险提示语 | 带 4.9% 首借两行 | **不带 4.9%**，用 7.2%–24% 三行版 |
| 适用客群 | 拉新、没借过的 | 看额度、看期限、比平台靠谱度的 |

写的时候自问一句：**把 4.9% 删掉，这篇还站得住吗？** 站不住就是写成低价版了，回炉。

## 输出四件套

| # | 产出物 | 规格 |
|-|-|-|
| 1 | 标题 | ≤20 字，**前 16 字**必须含关键词 |
| 2 | 首图文案 + 图片 | 文案 ≤20 字；图 1080×1440（3:4）PNG、sRGB |
| 3 | 正文 | **≤220 字**（风险提示语不计入） |
| 4 | 标签 | 5–8 个，**必带 #度小满 #急用钱 #缺钱** |

**这是图文笔记，不是视频脚本**——图片轮播 + 正文，没有口播、分镜、时长。信贷默认**一张图**。

权重次序（搜索场域关键词匹配度）：**图片 > 标题 > 正文 > 标签 > 评论区**。所以先想图，再想标题，最后写正文——不要倒着来。

## 生成流程

### Step 1　定输入

| 输入 | 取值 | 默认 |
|-|-|-|
| 搜索词 | 急用钱 / 借钱 / 贷款 / 周转 / 公积金贷款 / 度小满 … | 急用钱 |
| 人群 | 个人消费 / 小微企业主 | 个人消费 |
| 场景 | 生活应急 / 经营周转 / 信贷科普 | 生活应急 |

用户没给就按默认走，**并在输出时标注用了默认值**。

### Step 2　出标题

硬性规则，违反即重写：

- ≤20 字（汉字/全角标点 1 字符，英文/数字/半角 0.5 字符，emoji 计入）
- **前 16 字**必须含至少一个：`度小满 / 急用钱 / 缺钱 / 借钱 / 急需 / 周转 / 手头紧 / 没钱 / 缺几万 / 资金周转`
- emoji **1–2 个**，第 3 个起会被折叠
- 不写空泛感叹，要对得上真实的借款搜索意图

5 类句式与实例见 `references/标题公式.md`。

### Step 3　出图片

图片是权重最高的位置。规范与模板见 `references/首图规范.md`。

三条不能破的：

1. **底部必须有灰色小字风险提示语**——硬性过审要求，缺了直接不过
2. **左上角必须有度小满 logo**（用官方 app icon，不要手绘）
3. **高亮只能 2–4 字**，荧光黄 `#FFE94D` 或其他适配色

### Step 4　出正文

**先过红线**（完整版 `references/合规红线.md`）：

- 不能出现「低息 / 利息低 / 利率低 / 息费低」——**「低」字和息费类词同句出现即违规**，不要求连写
- 不能出现「最快 1 分钟到账 / 秒到 / 极速到账」等时效承诺
- 「20w」必须带「最高可达」，「24 期」必须带「最长」
- ≤220 字（风险提示语不计入）

三模块结构，打法与案例见 `references/正文三模块.md`：

| 模块 | 要完成什么 |
|-|-|
| ① 钩子（前 15 字） | 把标题展开，制造认知摩擦或情绪冲击，强行留人 |
| ② 铺垫 | **1–2 句**把钩子兑现成具体内容，引出度小满。不允许多次铺垫 |
| ③ 产品卖点 | 讲透 1–2 个，不全面铺开 |

**钱要素**（钱/借贷/额度/利率/支出/急用钱）首次出现必须落在**第 20–35 字**。早了破坏节奏，晚了用户划走。

卖点选择见 `references/产品卖点.md`——**卖点二（最高可达 20 万 / 最长 24 期）必须出现**，卖点一（大品牌）和卖点三（申请便捷）任选补位。

### Step 5　自检

**生成后逐项真打分，不达标先重写，不要输出。** 判定标准见 `references/评分卡.md`。

| 维度 | 核心问题 | 满分 |
|-|-|-|
| 图片 | 重点清晰突出、符合小红书原生风 | 4 |
| 标题 | 有搜索关键词、第一时间能抓住人 | 3 |
| 正文钩子 | 让用户感同身受，抓到真有借钱需求的人 | 2 |
| 产品卖点 | ≥2 个卖点，短平快讲清 | 1 |

**通过阈值：总分 ≥8（满分 10）且无 0 分项。**

| 情况 | 动作 |
|-|-|
| ≥8 且无 0 分项 | 输出 |
| 任一项 0 分 | **直接重写，不看总分**——0 分是结构性缺陷，补不回来 |
| <8 但无 0 分项 | **只改失分项**，不要整篇重写（会改坏已达标维度） |

### Step 6　输出格式

```
【输入】搜索词 x | 人群 x | 场景 x（默认值标注）
【标题】xxx（xx 字）
【首图文案】xxx（高亮：xx）
【正文】
xxx
【标签】#度小满 #急用钱 #缺钱 #xxx #xxx
【自检】图片 x/4 | 标题 x/3 | 钩子 x/2 | 卖点 x/1 | 总分 x/10
```

自检分必须真打，不能默认满分。低于阈值不要输出，先重写。
