# 小红书信贷内容工作台

本机网页工具，每天 11:00 使用已登录的小红书浏览器会话搜索“借钱 / 急用钱 / 贷款”，保存每个词自然排序前三笔记，并生成一篇通过非低价 Skill 规则校验的原创初稿。

## 启动

```bash
npm install
npm start
```

打开 `http://127.0.0.1:4173`，先点击“登录小红书”完成登录，再点击“立即更新”。保持服务运行时，任务会在 Asia/Shanghai 时区每天 11:00 执行。

默认使用 macOS 的 Google Chrome。Chrome 安装在其他位置时，可通过 `CHROME_PATH` 指定可执行文件。

## 安装为登录自启服务

```bash
chmod +x scripts/install-service.sh
./scripts/install-service.sh
```

安装后无需保持终端窗口打开，但电脑需要在每日 11:00 开机并处于登录状态。

## 边界

- 搜索结果受登录账号、地域和个性化推荐影响，不代表全平台统一榜单。
- 不绕过验证码、登录限制或平台访问控制；遇到验证时需人工处理。
- 自动生成内容只模仿结构和选题信号，不复制原文，不虚构借款成功经历。
- 发布前仍需业务与法务人工审核。
